# Sportocraft Sports & Events

Initial static Angular project structure using standalone components, TypeScript, SCSS, and Angular Router.

## Run

```bash
npm install
npm start
```

Build with `npm run build:prod`.

Routes: `/`, `/about`, `/sports-events`, `/corporate-events`, `/garba-navratri`, `/our-work`, `/case-studies`, `/contact`, `/thank-you`, `/privacy-policy`, `/terms`, plus a wildcard 404 route.
